# PangoZip

<img src="Resources/Icons/AppIcon-master.png" width="128" alt="PangoZip — золотистый панголин">

Установка перетаскиванием: [PangoZip 0.6.0 (предварительный релиз)](https://github.com/evn88/PangoZip/releases/tag/v0.6.0).

Нативный менеджер архивов для **macOS 26+**: SwiftUI, AppKit и официальный 7-Zip 26.04 (`7zz`). 

## Под капотом

PangoZip — самостоятельная нативная оболочка **на SwiftUI и AppKit поверх официального 7-Zip 26.04 (`7zz`)**. Движок уже включён в репозиторий; установка Homebrew, p7zip или отдельного 7-Zip не нужна. 

| Часть | Назначение |
|---|---|
| `Sources/PangoZipCore` | `Foundation.Process` для 7zz, разбор листинга, извлечение, транзакционное изменение архивов, временные сеансы и проверка путей |
| `Sources/PangoZipApp` | SwiftUI-интерфейс, AppKit-дерево, Quick Look, редактирование рабочих копий, перетаскивание через File Promises |
| `FinderExtension` | Finder Sync Extension с подменю PangoZip для множественного выделения |
| `PangoZipWorker.app` | Отдельный экземпляр приложения для фоновых команд Finder; показывает небольшое окно прогресса |
| `Tools/Uninstall.swift` | Встроенная программа удаления и отмены системной регистрации |
| `Resources/Engine` | Официальный universal 7zz для Apple Silicon/Intel, лицензии, документация и полный архив исходников 7-Zip |

Аргументы движку передаются напрямую, без shell. Для просмотра извлекается выбранный файл во временную папку. Изменения сначала применяются к рабочей копии архива, проверяются и затем атомарно заменяют оригинал, если он не был изменён другим процессом.

## Возможности

- Широкая таблица-дерево: имя, размер, даты создания/изменения, права и владелец. Если архив не хранит сведения, показан прочерк.
- Поиск по имени/пути, множественное выделение и нативная навигация клавиатурой.
- Контекстное меню по ПКМ: открыть, редактировать, извлечь выделенное, копировать путь, добавить файлы, сохранить изменения, удалить.
- Перетаскивание из архива в Finder извлекает копии выбранных файлов/папок через macOS File Promises. Перетаскивание файлов из Finder в таблицу добавляет их в архив; наведение на папку выбирает место добавления.
- Небольшой предпросмотр справа через Quick Look. Его можно скрыть кнопкой на панели или ⌘⇧P.
- Кнопки на панели показывают только иконки; названия и сочетания клавиш доступны в подсказках.
- Добавление файлов и папок в выбранную папку архива, удаление выбранного и открытие отдельных файлов.
- Редактирование через временную рабочую копию и явное сохранение обратно в архив.
- Подменю PangoZip прямо в основном контекстном меню Finder: открыть архивы, распаковать в выбранное место/здесь/в одноимённые папки, тестировать и создать новый ZIP/7z.
- Создание и извлечение показывают полосу, процент выполнения и текущий этап: подготовку, сжатие/извлечение, проверку и завершение. 100% появляется после сохранения результата; для нескольких архивов виден номер текущего.
- Упаковка и извлечение из Finder выполняются отдельным помощником с небольшим окном прогресса, без главного окна и значка Dock. Настройки сжатия доступны через PangoZip → Settings… (⌘,).

Изменение поддерживается для ZIP, 7z и TAR. RAR и остальные форматы открываются для чтения. Тип определяется по содержимому, а не по расширению. Многотомные архивы и архивы с исполняемой оболочкой не изменяются.

## Редактирование

1. Выберите файл и нажмите кнопку с карандашом или ⌘E.
2. Измените и сохраните его во внешнем редакторе.
3. Вернитесь в PangoZip и нажмите «Сохранить в архив» (иконка со стрелкой вниз) или ⌘S.

Сохранение завершает текущий цикл редактирования и удаляет сохранённую рабочую копию. Для следующего изменения вновь нажмите ⌘E. До закрытия архива несохранённые рабочие копии требуют решения: сохранить, не сохранять или отменить закрытие. Обычное «Открыть файл» создаёт копию для чтения и не отслеживает изменения; для записи используйте «Редактировать».

Добавление и удаление запрашивают подтверждение; совпадающие пути при добавлении заменяются. Архив изменяется на рабочей копии рядом с оригиналом, проверяется движком и заменяется атомарно. Ошибка или отмена до замены сохраняет исходный архив. Если оригинал изменился другим приложением, операция отклоняется. Шифрование ZIP/7z сохраняется; в пределах сеанса его политика сохраняется и после удаления всех записей.

## Клавиатура

| Сочетание | Действие |
|---|---|
| ⌘O | Открыть архив |
| ⌘W | Закрыть архив и удалить временные файлы |
| ⌘⇧A | Добавить файлы и папки |
| ⌘⌫ | Удалить выбранное |
| ⌘↩ | Открыть файл во внешнем приложении |
| ⌘E | Редактировать рабочую копию |
| ⌘⇧E | Извлечь выбранные файлы/папки |
| ⌘S | Сохранить рабочие копии в архив |
| ⌘⇧P | Скрыть/показать предпросмотр |
| ⌘F | Поиск |
| Escape | Отменить текущую обработку |

Стрелки, раскрытие дерева, ⌘A и множественное выделение работают нативно. Закрытие окна и ⌘Q также проверяют рабочие копии и выполняют очистку.

## Сборка и установка

Для готовой сборки скачайте `PangoZip-<version>-<arch>.dmg` из [GitHub Releases](https://github.com/evn88/PangoZip/releases): первый релиз 0.5.0 содержит сборку `arm64` для Apple Silicon. Готовая Intel-сборка пока не опубликована. Требуется macOS 26+; Xcode не нужен. Откройте образ, перетащите `PangoZip.app` на `Applications`, извлеките образ и запустите приложение из папки `Applications`. Вложенный помощник уже находится внутри приложения и регистрируется при первом запуске; установочный скрипт и пароль администратора ему не нужны. macOS может попросить разрешить Finder Extension через системные настройки. Инструкция: [docs/installation.txt](docs/installation.txt).

Предварительные релизы 0.5.0 и 0.6.0 имеют ad hoc подпись, без Developer ID и нотариализации Apple. macOS может заблокировать открытие загруженного приложения; успешный перенос в Applications сам по себе не устраняет ограничение Gatekeeper. Не отключайте системную защиту macOS.

Для сборки из исходников требуются macOS 26+, Xcode 26+ и Swift 6.2+. Сборка приложения создаётся для архитектуры текущего Mac; встроенный движок — universal arm64/x86_64. Движок и оригинальные лицензии уже в `Resources/Engine`; сетевых зависимостей для сборки нет.

```sh
git clone https://github.com/evn88/PangoZip.git
cd PangoZip
./scripts/build-app.sh
./scripts/install-app.sh --skip-build
open ~/Applications/PangoZip.app
```

Для разработки установочный скрипт `./scripts/install-app.sh` по-прежнему доступен как альтернативный способ установки из исходников. Основной DMG-путь использует перетаскивание приложения и регистрацию вложенных компонентов при первом запуске. Если подменю PangoZip не появилось, включите PangoZip в настройках расширений Finder. Старые Services сохранены как запасной способ запуска. Подробности: [docs/finder-integration.md](docs/finder-integration.md).

Для выпуска с Developer ID и нотариализацией Apple подготовлены `scripts/sign-app.sh` и `scripts/notarize-release.sh`. Однократная настройка сертификата и Keychain, команда выпуска и диагностика описаны в [docs/notarization.md](docs/notarization.md). Без сертификата обычная сборка остаётся ad hoc.

Для упаковки выполните `./scripts/package-dmg.sh`; при уже готовой сборке — `./scripts/package-dmg.sh --skip-build`. Скрипт формирует сжатый образ UDZO `build/PangoZip-<version>-<arch>.dmg`, берёт версию и архитектуру из приложения, проверяет подпись компонентов и целостность образа. В DMG находятся `PangoZip.app`, ссылка `Applications` на `/Applications` и `Read me.txt`; приложение включает расширение Finder, помощников, лицензии и исходники 7-Zip. Основной способ установки из DMG — перетаскивание приложения в Applications. `./scripts/package-app.sh` сохраняет ZIP-пакет для разработчиков.

Удаление: закройте приложение, дождитесь фоновых операций и запустите `./scripts/uninstall-app.sh` или `Uninstall PangoZip.command` из пакета. В настройках доступна кнопка «Показать программу удаления…» для вложенной команды. Деинсталлятор отключает расширение, снимает регистрацию приложения/помощника и переносит весь комплект в Корзину. Настройки сжатия сохраняются; при ошибке перемещения регистрация восстанавливается.

При обычном переносе приложения в Корзину Finder Sync проверяет доступность основного приложения и помощника перед показом меню и исполнением команд. Для удалённого приложения или пути в `.Trash`/`.Trashes` новое меню не создаётся. Уже открытое меню нужно закрыть и открыть заново. Приложение не устанавливает LaunchAgent/LaunchDaemon и не оставляет внешний помощник. Системный реестр расширений обслуживает macOS; мгновенная очистка всех системных кэшей при ручном удалении не гарантируется.

Меню в Finder следует привычной схеме 7-Zip:

- «Добавить в архив…» создаёт **новый** архив: выбор имени/папки, формата, уровня сжатия, solid, потоков и необязательного пароля.
- «Добавить в “имя.7z”» и «Добавить в “имя.zip”» сразу создают новый архив рядом с выделением, используя настройки по умолчанию.
- Для архивов: «Открыть архив», «Распаковать…», «Распаковать здесь», «Распаковать в “имя/”» и «Тестировать архив».

Упаковка включает всё выделение; несколько файлов помещаются в один новый архив. В смешанном выделении открытие/распаковка/тестирование берут только архивы. Несколько открываемых архивов получают независимые экземпляры приложения. Команды распаковки/тестирования и создания выполняются отдельным helper без основного браузера; диалог появляется только для команды с многоточием или запроса пароля. После успеха/отмены helper закрывается, при ошибке остаётся сообщение.

Глобальные настройки задают начальные параметры диалога создания и параметры быстрых команд. При пароле используются AES-256 для ZIP и шифрование заголовков 7z. Пароль не сохраняется в настройках.

«Распаковать здесь» не создаёт обёртку с именем архива; «Распаковать…» позволяет выбрать папку назначения. «Распаковать в “имя/”» создаёт отдельную папку для каждого архива. Имена `Photos.tar.gz` превращаются в `Photos`. Занятые имена получают числовой суффикс без перезаписи. Добавление файлов **в уже открытый архив** остаётся отдельной функцией панели менеджера и перетаскивания файлов в таблицу.

Откройте `Package.swift` в Xcode для разработки. Проверки:

```sh
swift test
swift format lint --strict --recursive Sources FinderExtension Tests Package.swift
```

Сборка создаётся для архитектуры текущего Mac и подписывается ad hoc. Для собственной подписи задайте `PANGOZIP_SIGNING_IDENTITY` при сборке. Developer ID и notarization для распространения не входят в эту версию.

## Подробный прогресс

Создание, извлечение и экспорт показывают обработанный и общий объём, среднюю скорость текущего этапа, прошедшее время, оценку оставшегося времени этапа, число файлов и размер создаваемого архива. При извлечении также показывается текущий файл. Мегабайты десятичные (1 МБ = 1 000 000 байт).

Промежуточные байты рассчитываются по процентам 7zz и помечены `≈`; скорость и оставшееся время также являются оценками. При переходе от сжатия к проверке счётчик относится уже к проверяемым данным. Время всей операции продолжает идти. 100% появляются после проверки и публикации результата. Подробности и проверки: [docs/release-0.5.0.md](docs/release-0.5.0.md).

При первом и последующих запусках из `/Applications` или `~/Applications` приложение штатно регистрирует себя и встроенный worker. Расширение обнаруживает macOS; если оно выключено, PangoZip показывает кнопку системной настройки. Отдельные установочные команды не требуются. [Проверка установки 0.6.0](docs/installation-0.6.0.md).

## Временные файлы и ограничения

Временные файлы сеанса удаляются после закрытия/смены архива и штатного выхода, когда отменённые операции завершены. Рабочие каталоги защищены правами 0700. Остатки после аварии, включая транзакционные копии рядом с архивом, очищаются при следующем запуске; активные экземпляры не затрагиваются благодаря файловой блокировке. При недоступном диске или системном запрете удаления очистка может потребовать повторного запуска после восстановления доступа.

Предпросмотр ограничен 200 MiB на файл, листинг — 32 MiB/100 000 записей, отдельная операция движка — 120 секундами. Симлинки и специальные файлы не открываются для просмотра/редактирования. Небезопасные и неоднозначные пути отклоняются. Пароль хранится в памяти и передаётся 7zz аргументом процесса: локальные инструменты просмотра процессов могут его видеть.

Quick Look определяет поддержку документов. Просмотр файлов внутри вложенных архивов пока не реализован. Для выделенных объектов можно выбрать папку извлечения через ПКМ или ⌘⇧E. Извлечение целого архива ограничено 100 GiB, ссылки и специальные файлы отклоняются. tar.gz/tgz, tar.bz2 и tar.xz снимают слой сжатия и извлекают содержимое TAR. Solid-архив может требовать декодирования соседних данных для доступа к одному файлу.

Требования и проверки: [docs/editing-specification.md](docs/editing-specification.md), [docs/editing-verification.md](docs/editing-verification.md).

Взаимодействие с файлами: [docs/file-interactions.md](docs/file-interactions.md).

## Переименование

Приложение и Swift-модули называются PangoZip; папка проекта — `pangozip`. Идентификаторы приложения, фонового помощника и Finder Sync используют `app.pangozip`. При первом запуске переносятся прежние настройки сжатия. Служебные имена временных рабочих папок сохранены для совместимости восстановления и очистки данных предыдущей версии.

## Разработка и обратная связь

Откройте `Package.swift` в Xcode. Для небольшого исправления создайте ветку, внесите изменение и проверьте его командами `swift test`, `swift format lint --strict --recursive Sources FinderExtension Tests Tools Package.swift` и `./scripts/build-app.sh`. Тесты создают собственные архивы во временных каталогах; не используйте пользовательские архивы для автоматических проверок.

Последняя локальная проверка: 70 XCTest, строгий формат Swift, release-сборка и подпись. Результаты полного ревью и исправления: [docs/code-review.md](docs/code-review.md). Ранее проверенный цикл установки/удаления и прогресс: [проверка установки](docs/installation-verification.md), [проверка прогресса](docs/progress-verification.md). Автоматизация не подтвердила полный перенос файлов перетаскиванием между окнами Finder и приложения; ручная проверка этого сценария описана в [docs/file-interactions.md](docs/file-interactions.md).

Сообщения об ошибках и предложения: [GitHub Issues](https://github.com/evn88/PangoZip/issues). Укажите версию macOS/PangoZip, формат архива и шаги воспроизведения. Не публикуйте пароли, личные файлы и конфиденциальные архивы; используйте безопасный пример.
