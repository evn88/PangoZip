# Локализация

PangoZip поддерживает `en`, `ru`, `sr-Latn`, `de`, `fr`, `es`, `it`, `pt`, `pl`, `uk`, `tr`, `zh-Hans`, `ja`, `ko`. Сербский использует латиницу, китайский — упрощённые иероглифы, португальский — европейский вариант. Язык выбирается macOS, включая отдельную настройку языка приложения. Резервный язык — английский; формат чисел и дат соответствует региональным настройкам системы.

Каталоги находятся в `Sources/PangoZipCore/Resources/<language>.lproj/Localizable.strings`. Пользовательские строки вызываются через `L10n.tr`. Подстановки передаются отдельными строковыми аргументами, а в переводах обозначаются `%1$@`, `%2$@` и далее. Их порядок можно менять, количество и номера необходимо сохранять. Счётчики используют подписи вида «Объектов: 3», без склоняемых выражений вида «3 объекта».

SwiftPM подключает каталог через `Bundle.module`. Скрипт сборки копирует `.lproj` в основной комплект приложения, worker и Finder extension, которые используют собственный Bundle. Удалитель читает каталог родительского приложения. Пункты Services локализуются отдельными `ServicesMenu.strings`; тип документа — `InfoPlist.strings`.

Проверки: `swift test`, `swift format lint --strict --recursive Sources Tests Package.swift`, `scripts/build-app.sh`. `LocalizationTests` проверяет полный набор локалей, одинаковые ключи, непустые переводы, позиционные подстановки и сохранение пользовательских имён файлов.

Официальные источники:

- [Apple: Localizing package resources](https://developer.apple.com/documentation/xcode/localizing-package-resources)
- [Apple: Services Properties](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/SysServices/Articles/properties.html)

Переводы требуют дальнейшей редакторской проверки носителями языка; автоматические проверки подтверждают структуру каталогов, но не заменяют языковую вычитку.

Проверено 17 октября 2026: 87 тестов прошли, strict Swift Format и release-сборка завершились успешно. Проверка подписи `codesign --verify --deep --strict` прошла. Отдельный процесс с production-helper подтвердил выбор всех 14 языков через `-AppleLanguages`, английский fallback для неподдерживаемого языка и корректные подстановки. Ресурсы в app, worker и расширении Finder побайтно сверены с исходниками. Проверено сохранение перевода сообщения удалителя после перемещения временного тестового комплекта. Визуальная проверка всех локалей не проводилась.

## Визуальная проверка

17 октября 2026 приложение запускалось с временным `-AppleLanguages`, без изменения настроек macOS. Через CUA проверены немецкие главное окно и настройки архивации/приложения, французские настройки и сведения о папке в ZIP, польские настройки, японские настройки и сведения о файле вместе с Quick Look. Дополнительно проверено немецкое штатное окно создания архива с параметрами сжатия и полями пароля; создание отменено. В проверенных окнах обрезаний подписей не обнаружено: длинные пояснения и название метода сжатия переносятся на несколько строк. Это выборочная визуальная проверка; полнота ключей и подстановок автоматически проверяется для всех 14 языков.

После интеграции кэша размеров папок итоговый прогон: 88 тестов без ошибок, strict Swift Format, release-сборка и проверка подписи прошли. Приложение возвращено к русскому интерфейсу с ранее открытым `ML.7z`.

18 октября 2026 добавлены четыре ключа для колонки сжатия, её объяснения, ожидания фонового расчёта и подсказки о solid compression. Все 14 каталогов содержат 235 ключей. Иконка вопроса в настройках и окне создания архива использует штатный [SwiftUI help](https://developer.apple.com/documentation/swiftui/view/help(_:)-6oiyb), который также задаёт подсказку доступности. Объяснение solid проверено по [официальному руководству bundled 7-Zip](../Resources/Engine/MANUAL/cmdline/switches/method.htm#Solid).

Финальная проверка новой подсказки: немецкое окно создания ZIP/7z и русские настройки. Подписи и вопросик видны без обрезания; accessibility показывает правильное название переключателя и полный Help. Декоративная иконка скрыта от VoiceOver, объяснение доступно на самом переключателе. CUA не предоставляет наведение; отдельный всплывший tooltip на снимке не зафиксирован. Тестовое создание отменено, приложение возвращено на русский язык.
