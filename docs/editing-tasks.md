- [x] Настройки формата, степени сжатия, solid и потоков.
- [x] Интеграционные тесты и ручная проверка прямого меню, фоновых операций и передачи настроек.

## Взаимодействие внутри менеджера

- [x] Контекстное меню с выбором строки, поддержкой множественного выделения и доступностью команд.
