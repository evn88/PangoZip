# Взаимодействие с содержимым архива

## Контекстное меню

ПКМ по строке выбирает её, если она не входит в текущее выделение; ПКМ по уже выбранной строке сохраняет множественное выделение. На пустом месте доступны добавление в корень и сохранение рабочих копий. Доступность команд учитывает формат архива, выбор файла/папки, рабочие копии и текущую операцию.

Меню: открытие одного файла, редактирование, извлечение выбранного, копирование путей, раскрытие/сворачивание одной папки, добавление, сохранение изменений и удаление. Извлечение также доступно из меню «Архив» по ⌘⇧E.

## Перетаскивание

Внешние локальные файлы/папки из Finder принимаются через native NSOutlineView drop. Drop на папку добавляет в неё, на файл — в его родительскую папку, на пустое место — в корень. При read-only формате и выполнении операции drop отклоняется. После завершения жеста показывается обычное подтверждение добавления с предупреждением о замене совпадающих путей. Перенос нескольких файлов обрабатывает всё выделение.

Из таблицы выдаётся NSFilePromiseProvider на каждый верхний выбранный объект. Выбранный потомок выбранной папки не выдаётся второй раз. Назначение — Finder или другая программа с поддержкой macOS File Promises. Извлечение начинается при запросе promise после отпускания мыши; отменённый жест не распаковывает данные. Исходный архив сохраняет файлы: это копирование, не удаление. Перемещение и переименование записей внутри архива пока не добавлены.

Папка сохраняет дочернюю структуру. При обычном извлечении одинаковые базовые имена получают числовой суффикс. File Promise использует точное имя/URL, предоставленное получателем; существующий объект в этом месте не перезаписывается.

## Жизненный цикл

Снимок содержит путь и session ID. Delegate удерживается через provider.userInfo, поскольку AppKit хранит delegate слабо. Запросы promise исполняются последовательно, UI не блокируется работой 7zz. Пароль запрашивается в штатном sheet; отмена возобновляет ожидающий callback с ошибкой. Открытие другого архива и изменения блокируются на время drag/export. Закрытие архива и приложения отменяет и дожидается начатых export tasks; поздний запрос закрытого сеанса получает sessionExpired. Неисполненный lease после завершённого drop снимается через 120 секунд, чтобы не блокировать UI навсегда при некорректном получателе.

Выходные данные сначала пишутся в транзакционную папку рядом с назначением, проверяются по объявленному размеру и fingerprint оригинала, получают quarantine/даты/права. Публикация promise проходит через NSFileCoordinator и атомарный RENAME_EXCL. Временные каталоги удаляются при успехе, ошибке и отмене. Ссылки/специальные файлы и неоднозначные пути отклоняются; лимит 100 GiB на выбранный верхний объект.

## Проверки 11.10.2026

37 core XCTest и 2 app XCTest: вложенные/пустые папки, отбор верхних объектов, коллизии базовых имён, точный URL promise, запрет перезаписи, лимит, отмена, закрытый сеанс; последовательные callback нескольких File Promises и снятие drag lease.

Ручной UI: меню ПКМ на Photo.txt, корректное выделение и доступность действий; «Извлечь выбранное…» создала Photo.txt в build/InteractionDemo/destination. Основное окно и предпросмотр работали с тестовым ZIP.

Полный жест между окнами вручную не подтверждён: cua_repl.drag вернул noWindowsAvailable даже после повторной привязки к окну. Native validateDrop/acceptDrop и взаимодействие с другими получателями требуют дальнейшей ручной проверки. Код File Promise и работа с фактическими выходными файлами проверены app-тестами. Использованы только собственные fixture, пользовательские архивы не изменялись.

API: [NSFilePromiseProviderDelegate](https://developer.apple.com/documentation/appkit/nsfilepromiseproviderdelegate), установленный AppKit SDK для NSOutlineView/NSFilePromiseProvider.
