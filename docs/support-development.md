# Поддержка разработки PangoZip

В настройках подготовлен раздел «Поддержать PangoZip» с кнопкой «Поддержать разработку…». Она открывает внешнюю HTTPS-страницу в браузере по умолчанию через `NSWorkspace`. Если macOS не принимает запрос открытия, приложение показывает сообщение об ошибке.

## Выбранный сервис

Владелец выбрал GitHub Sponsors. Инструкция для аккаунта `evn88` и выплат в Сербии находится в [github-sponsors.md](github-sponsors.md). Повторная проверка GitHub API 11 октября 2026 года подтвердила публичный профиль Sponsors `evn88` и адрес https://github.com/sponsors/evn88. Ссылка включена в приложении; `.github/FUNDING.yml` содержит `github: evn88`. Готовность выплат не проверялась.

## Настройка ссылки

Единственный источник адреса — строковый ключ `PangoZipSupportURL` в `Resources/Info.plist`. Строка содержит проверенный адрес https://github.com/sponsors/evn88. При пустом, отсутствующем или недопустимом значении весь раздел скрыт. Подставного адреса и автоматического перехода на сайт платёжного сервиса нет.

После получения ссылки от владельца:

1. Указать действительный HTTPS-адрес принадлежащей владельцу страницы поддержки в `PangoZipSupportURL`. Не добавлять секреты и учётные данные. Путь и параметры ссылки передаются без изменений.
2. Выполнить `swift test`, `swift format lint --strict --recursive Sources Tests Package.swift` и `scripts/build-app.sh`.
3. В собранном приложении открыть настройки и нажать кнопку. Проверить открытие страницы нужного получателя в браузере, валюту и возможность выбрать сумму. Для проверки перехода совершать платёж не требуется.

Существующий скрипт сборки уже копирует `Resources/Info.plist` в комплект приложения. Изменение скриптов сборки и нотариализации для поддержки не нужно. Адрес не хранится в пользовательских настройках; смена страницы требует новой сборки.

Платёжный сервис можно заменить без изменений SwiftUI. Приложение не создаёт платёжные сессии, не принимает реквизиты карт и не хранит сведения о платежах.

## Как получить публичную страницу PayPal

«Форма поддержки» — внешняя страница оплаты, где сторонник видит получателя, вводит сумму и подтверждает перевод. В PangoZip нужен её публичный URL.

- PayPal Donate исключён: при проверке владельцем PayPal сообщил, что создание donation page недоступно в стране аккаунта. Повторно отправлять владельца в конструктор Donate не нужно.
- Резервный вариант — персональная ссылка PayPal.Me: Сербия включена в [официальный список стран](https://www.paypal.com/paypalme/pages/countries). Владелец может открыть [PayPal.Me](https://www.paypal.com/paypalme/) под существующим аккаунтом и получить свою ссылку; также она доступна в профиле настроек аккаунта. [Официальный FAQ](https://www.paypal.com/us/cshelp/article/paypalme-frequently-asked-questions-help432).
- Нужна ссылка, фактически созданная владельцем. Доступность конкретного аккаунта и тип платежа проверяются в PayPal; комиссия не становится нулевой из-за использования PayPal.Me. При недоступности PayPal.Me можно рассмотреть Ko-fi с существующим PayPal или GitHub Sponsors.

Аккаунты и платёжные услуги в рамках этой задачи не создаются и не подключаются. Публичная ссылка GitHub Sponsors подтверждена через GitHub API.

## Настройка страницы Ko-fi с существующим PayPal

Ko-fi перечисляет подключение личного или бизнес-аккаунта PayPal; поступления идут напрямую в PayPal. Публичного подтверждения доступности именно аккаунта владельца нет. Отказ PayPal в создании Donate-страницы сам по себе не доказывает недоступность подключения Ko-fi: это отдельный сценарий. Возможность принимать платежи зависит от ограничений самого PayPal и подтверждается при подключении аккаунта. [Получение денег](https://help.ko-fi.com/hc/en-us/articles/115003980093-How-do-I-get-paid), [FAQ](https://help.ko-fi.com/hc/en-us/articles/29745501815709-Beginner-FAQs).

Владелец может настроить страницу самостоятельно:

1. Создать страницу автора на Ko-fi с названием PangoZip и доступным именем ссылки.
2. Открыть `Settings > Payment`, выбрать подключение PayPal и войти в существующий сербский аккаунт.
3. Выбрать валюту EUR и использовать разовые взносы.
4. В `Settings > Payment` выключить `Contributor`: у новых страниц он включён по умолчанию. Без него разовые взносы не облагаются комиссией Ko-fi; PayPal продолжает взимать свои комиссии. Подписки и другие платные функции имеют отдельные тарифы. [Инструкция Contributor](https://help.ko-fi.com/hc/en-us/articles/25143210488477-Contributor-status).
5. Добавить значок приложения и описание: «PangoZip — нативный менеджер архивов для macOS. Ваша поддержка помогает развивать приложение, исправлять ошибки и добавлять новые возможности. Спасибо!»
6. Открыть публичную страницу, проверить отображение проекта и доступность PayPal, скопировать её HTTPS-ссылку для `PangoZipSupportURL`.

[Официальное руководство по созданию страницы](https://help.ko-fi.com/hc/en-us/articles/360014098514-Getting-started-on-Ko-fi).

### Присланный фрагмент PayPal SDK

Владелец прислал обе части встраивания PayPal: загрузчик SDK с валютой EUR и вызов `paypal.HostedButtons` с ID конкретной кнопки. Это веб-кнопка, а не скопированный публичный URL оплаты. Для резервного варианта нужно открыть эту кнопку в панели PayPal и скопировать платёжную ссылку через Payment Links; проверка получателя и страницы ещё не выполнена. `client-id` и скрипты в приложение не переносятся. [Создание и копирование ссылки PayPal](https://developer.paypal.com/payment-links-buttons/create-payment-link/).

Для нативного приложения по-прежнему нужен публичный HTTPS-адрес, скопированный из Ko-fi, PayPal.Me или PayPal Payment Links. Загружать SDK в интерфейс SwiftUI не требуется.

### Дополнительные расходы PayPal

Для личного аккаунта RS вывод на подходящую карту стоит 1% с минимумом €0,25 и максимумом €10 при выводе в EUR. Комиссии банка могут добавляться: [тарифы PayPal Consumer RS](https://www.paypal.com/rs/digital-wallet/paypal-consumer-fees). Это не подтверждает доступность конкретной карты владельца.

При конвертации полученных средств или баланса PayPal RS указывает надбавку 3% к базовому курсу: [раздел Currency Conversions](https://www.paypal.com/rs/business/paypal-business-fees). Приём и вывод в одной валюте может помочь избежать конвертации, если такой вывод поддерживают аккаунт и карта/банк.

Пример расчёта по стандартному коммерческому тарифу, без вывода и конвертации: из €5 от отправителя из ЕЭЗ/Великобритании комиссия составит около €0,58, остаток около €4,42; из €10 — около €0,82 и €9,18 соответственно. Это расчёт для сравнения; фактическая комиссия зависит от типа платежа.

Текущий выбор владельца — GitHub Sponsors. Публичный профиль `evn88` проверен; приложение и файл FUNDING используют его. Статус подключения выплат проверяется владельцем в панели Sponsors. PayPal и Ko-fi остаются резервными вариантами.
