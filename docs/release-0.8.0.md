# PangoZip 0.8.0

## Новое

- **Служебные файлы систем.** В настройках появились две опции, обе включены по умолчанию:
  - «Приложение → Просмотр архивов → Скрывать служебные файлы систем». В списке архива не показываются `__MACOSX`, `.DS_Store`, AppleDouble-файлы `._*`, `.Spotlight-V100`, `.Trashes`, `.fseventsd`, `Thumbs.db`, `desktop.ini`, `$RECYCLE.BIN` и подобные. Это касается и дерева, и поиска. Сами записи остаются в архиве, а при распаковке всего архива они извлекаются.
  - «Архивация → Не добавлять служебные файлы систем». Эти файлы не попадают ни в новые архивы (окно «Добавить в архив…», быстрые команды ZIP/7z, создание из окна архива), ни в существующий архив при добавлении файлов. Служебные файлы пропускаются уже при копировании во временную папку, поэтому прогресс и размер считаются без них.
- **Предпросмотр Quick Look (пробел) переработан.** Вместо дублирующегося имени архива показывается сводка: число объектов, размер и формат. Добавлены поиск, выбор нескольких объектов, иконки файлов, колонка «Тип», размеры папок и контекстное меню («Извлечь…», «Копировать путь в архиве»). Есть кнопки «Извлечь выбранное…» и «Распаковать всё…», после распаковки — «Показать в Finder». Поле пароля показывается только для зашифрованных архивов.
- **Сайт pangozip.app.** Ссылка добавлена в окно «О программе», в меню «Справка → Сайт PangoZip» и во все README.

## Исправления

- Открываются и распаковываются архивы TAR.BZ2/TBZ2 и TAR.ZST. bzip2 и zstd не хранят исходный размер, поэтому PangoZip узнаёт его проверкой потока; строгие проверки размера при распаковке сохранены.
- Открываются архивы TAR.XZ/TXZ, у которых 7zz не выводит имя внутреннего файла.
- Открываются TAR-архивы, созданные утилитой `tar` в macOS: строка `Warnings: N` от PAX-заголовков больше не ломает разбор списка. AppleDouble-файлы `._*`, которые 7zz при распаковке превращает в расширенные атрибуты, больше не считаются ошибкой.
- Распаковываются TAR.GZ, внутренний TAR которых больше 4 ГиБ.
- Внизу окна архива больше нет лишней горизонтальной прокрутки: свободную ширину забирает колонка «Имя».
- Изменение скачанного архива сохраняет отметку карантина (quarantine).
- Папки без права записи для владельца корректно публикуются при распаковке и удаляются из временных папок.
- Слово «password» в имени файла больше не принимается за запрос пароля.
- Закрыто окно гонки при откате последнего изменения.
- Перетаскивание невыделенной строки берёт эту строку, а не текущее выделение; Esc не сбрасывает предпросмотр; устаревшая кнопка «Повторить» скрывается.
- Временные папки называются `app.pangozip.workspaces` и `.pangozip-*` вместо старого названия `zipevra`. Оставшиеся от прежних версий папки по-прежнему восстанавливаются и удаляются.

## Проверка

`swift test` (Core, App, Preview), строгая проверка Swift Format, тесты Python для релизных скриптов и `scripts/build-app.sh` проходят. Новые регрессионные тесты охватывают TAR.BZ2/TBZ2/TAR.ZST, TAR из macOS `tar`, распознавание и фильтрацию служебных файлов, исключение их при создании и пополнении архива, а также ширину таблицы относительно окна. Вид окна и Quick Look вручную не проверялись.
