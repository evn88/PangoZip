# Ревью PangoZip 0.4.3

Дата: 11.10.2026. Проверен собственный код приложения, архивного ядра, Finder Sync и программы удаления, все тесты, Package.swift, plist и entitlements, скрипты сборки/установки/удаления/упаковки, GitHub Actions, документация, лицензии и правила Git. К явным функциям, инициализаторам и deinit добавлены русские документирующие комментарии: назначение, существенные ограничения и порядок освобождения ресурсов. Вычисляемые свойства и замыкания не превращались в отдельные функции ради комментариев.

Сторонние файлы 7-Zip не изменены. Проверены комплектность лицензий, включение полных исходников и совпадение SHA-256 движка и архива исходников с PROVENANCE.md. Полный аудит стороннего C++-кода 7-Zip не выполнялся. У иконок проверены размеры PNG 16–1024 px и включение ICNS в комплект расширения.

## Иконка Finder и автоматизация

Главный пункт подменю PangoZip использует цветную иконку приложения 16×16 pt. Ресурс находится в `Contents/Resources/AppIcon.icns` самого расширения: ему не требуется доступ к ресурсу родительского приложения. При недоступности ресурса остаётся системный символ архива.

В GitHub Actions добавлены строгая проверка формата Swift, синтаксиса каждого shell-скрипта, сборка полного `.app` с расширением и программой удаления, проверка подписи. Эти шаги дополняют существующие сборку Swift Package и тесты.

## Проверки и границы

- `swift test`: 48 тестов ядра и 5 тестов приложения, 0 ошибок.
- `swift format lint --strict --recursive Sources FinderExtension Tests Tools Package.swift`: успешно.
- `bash -n` для каждого скрипта и `plutil -lint` для четырёх plist: успешно.
- SHA-256 bundled 7zz и полного архива исходников совпадают с записанными в PROVENANCE.md значениями.
- `scripts/build-app.sh`: release-сборка успешна; расширение, worker и программа удаления включены. Устаревший маркер предыдущей сборки отсутствует, ICNS расширения совпадает с исходным ресурсом.
- `codesign --verify --deep --strict`: собранное и установленное приложение успешно проверены.
- `scripts/package-app.sh --skip-build`: обновлён `build/PangoZip-Installer.zip`.
- `scripts/install-app.sh --skip-build`: установлена 0.4.3, PlugInKit подтверждает активное расширение этой версии из `~/Applications/PangoZip.app`.
- В настоящем Finder на папке `Input` вручную через UI подтверждены прямое подменю PangoZip, цветная иконка приложения и команды создания нового архива. Пользовательские файлы этой проверкой не изменялись.

Сборка выполняется на Apple Silicon для macOS 26 и подписывается ad hoc. Детерминированные тесты используют собственные файлы и настоящий bundled 7zz; shell-обёртки с задержками используются только в тестах.

Проверка не подтверждает отсутствие всех возможных ошибок. Не выполнены полный перенос файлов мышью между окнами, аудит VoiceOver/всех вариантов фокуса, тест на Intel, notarization и проверка всех сторонних Quick Look providers. Прежние отчёты в docs сохраняют даты и результаты соответствующих этапов.
