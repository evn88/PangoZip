PangoZip для macOS 26+

Установка из DMG (Xcode и исходники PangoZip не нужны):
1. Выберите образ PangoZip-<version>-<arch>.dmg для архитектуры вашего Mac: arm64 для Apple Silicon, x86_64 для Intel. Откройте образ.
2. Закройте ранее установленный PangoZip и дождитесь завершения фоновых операций.
3. Запустите Install PangoZip.command с открытого образа. Установщик проверит подпись и компоненты, скопирует приложение в ~/Applications и зарегистрирует расширение Finder и вложенный помощник. При обновлении предыдущая версия сохраняется до успешной регистрации. Не запускайте PangoZip.app непосредственно с образа и не заменяйте установку простым перетаскиванием: для меню Finder нужна регистрация компонентов.
4. После успешной установки извлеките образ и откройте PangoZip из ~/Applications.
5. Если macOS требует включения расширения, откройте PangoZip → Settings → «Настроить расширение Finder…» и включите PangoZip.

Образ доступен только для чтения. Установщик не записывает файлы на него; временные файлы установки создаются рядом с целевым приложением и удаляются при завершении.
Для ZIP-пакета сначала распакуйте весь PangoZip-Installer.zip, затем выполните шаги 2–5 из полученной папки (извлекать образ не требуется).

Удаление:
1. Закройте PangoZip и дождитесь завершения фоновых операций.
2. Запустите Uninstall PangoZip.command из открытого образа или распакованного пакета. Расширение отключается, регистрация отменяется, приложение со всеми вложенными компонентами перемещается в Корзину. Настройки сжатия сохраняются.
Команда удаления также находится внутри установленного приложения: Contents/SharedSupport/Uninstall PangoZip.command; её можно показать из настроек приложения.
Если приложение установлено в другой каталог, передайте его путь команде удаления из Terminal.

При обычном перемещении приложения в Корзину расширение проверяет наличие основного приложения и помощника перед каждым показом меню и запуском команды. Уже открытое контекстное меню нужно закрыть и открыть заново. Отдельных LaunchAgent, LaunchDaemon или установленных вне приложения helper нет.

Подпись и ограничения:
Текущая сборка подписана ad hoc, без сертификата Developer ID и нотариализации Apple. Это не подтверждённая Apple подпись разработчика; macOS может заблокировать открытие загруженного приложения или команды установки. Наличие DMG и успешная проверка целостности не отменяют эту проверку. Не отключайте системную защиту macOS. Автоматический проход Gatekeeper для загруженной сборки не подтверждён.

Лицензии:
Приложение включает собственную MIT-лицензию, уведомления, лицензии 7-Zip/LGPL/unRAR, сведения о происхождении движка и полный официальный архив исходников соответствующей версии 7-Zip. Они находятся в Contents/Resources, а также в ресурсах вложенного помощника.
