PangoZip для macOS 26+

Установка:
1. Распакуйте весь пакет PangoZip-Installer.zip.
2. Закройте ранее установленный PangoZip и дождитесь фоновых операций.
3. Запустите Install PangoZip.command. Приложение будет установлено в ~/Applications вместе с расширением Finder и помощником.
4. Если macOS требует включения расширения, откройте PangoZip → Settings → «Настроить расширение Finder…» и включите PangoZip.

Удаление:
1. Закройте PangoZip и дождитесь завершения фоновых операций.
2. Запустите Uninstall PangoZip.command из пакета. Расширение отключается, регистрация отменяется, приложение со всеми вложенными компонентами перемещается в Корзину. Настройки сжатия сохраняются.
Команда удаления также находится внутри приложения: Contents/SharedSupport/Uninstall PangoZip.command.

При обычном перемещении приложения в Корзину расширение проверяет наличие основного приложения и помощника перед каждым показом меню и запуском команды. Уже открытое контекстное меню нужно закрыть и открыть заново. Отдельных LaunchAgent, LaunchDaemon или установленных вне приложения helper нет.

Текущая сборка подписана ad hoc и предназначена для локального использования. Для публичного распространения нужны Developer ID и нотариализация Apple. Не отключайте системную защиту macOS.
