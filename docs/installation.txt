PangoZip для macOS 26+

Установка из DMG (Xcode и исходники PangoZip не нужны):
1. Выберите образ PangoZip-<version>-<arch>.dmg для архитектуры вашего Mac: arm64 для Apple Silicon, x86_64 для Intel. Откройте образ.
2. Перетащите PangoZip.app на Applications в окне образа и дождитесь копирования.
3. Извлеките образ, затем откройте PangoZip из папки Applications.
4. При первом запуске система может попросить разрешить Finder Extension. Откройте настройки расширений Finder в системных настройках и включите PangoZip.

Вложенный помощник уже находится внутри приложения и регистрируется при первом запуске. Установочный скрипт и пароль администратора помощнику не нужны. Если macOS заблокирует запуск загруженного приложения, это связано с подписью и проверкой Gatekeeper. Текущая сборка подписана ad hoc, без сертификата Developer ID и нотариализации Apple, поэтому предупреждение Gatekeeper может появиться. Обычный перенос в Applications не устраняет это ограничение; не отключайте системную защиту и не обходите Gatekeeper.

Удаление:
1. Закройте PangoZip и дождитесь завершения фоновых операций.
2. Переместите PangoZip.app из Applications в Корзину. Настройки сжатия сохраняются.

Для служебных сценариев сохранена встроенная программа удаления. При обычной установке и удалении запускать команды не нужно.

При обычном перемещении приложения в Корзину расширение проверяет наличие основного приложения и помощника перед каждым показом меню и запуском команды. Уже открытое контекстное меню нужно закрыть и открыть заново. Отдельных LaunchAgent, LaunchDaemon или установленного вне приложения helper нет.

Подпись и ограничения:
Текущая сборка подписана ad hoc, без сертификата Developer ID и нотариализации Apple. Это не подтверждённая Apple подпись разработчика; macOS может заблокировать открытие загруженного приложения. Наличие DMG и успешная проверка целостности не отменяют эту проверку. Не отключайте системную защиту macOS. Автоматический проход Gatekeeper для загруженной сборки не подтверждён.

Лицензии:
Приложение включает собственную MIT-лицензию, уведомления, лицензии 7-Zip/LGPL/unRAR, сведения о происхождении движка и полный официальный архив исходников соответствующей версии 7-Zip. Они находятся в Contents/Resources, а также в ресурсах вложенного помощника.
