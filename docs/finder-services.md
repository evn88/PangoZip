# Резервные Services Finder

Основная интеграция теперь реализована через прямое подменю Finder Sync: [finder-integration.md](finder-integration.md). Ниже описан сохранённый резервный механизм Services; команда «Добавить в архив PangoZip…» теперь тоже запускает создание нового архива через helper. При холодном запуске Services macOS может предварительно открыть главное приложение.

PangoZip объявляет две штатные macOS Services для выбранных в Finder локальных файлов и папок: «Открыть архив в PangoZip» и «Добавить в архив PangoZip…». macOS может показывать их в подменю «Службы» контекстного меню или в меню приложения Finder. Первый пункт передаёт приложению выбранный путь как запрос открытия; второй передаёт весь выбранный набор файлов и папок обработчику добавления.

Сервисы принимают современные file URL из pasteboard и резервно читают список путей старого формата. Запросы, пришедшие при холодном запуске до готовности основного окна и модели, сохраняются в очереди и доставляются после вызова `FinderServices.configure`. Обработчик приложения должен назначить экземпляр как `NSApp.servicesProvider` до поступления запросов и приём файлов из системного `open` перенаправлять через `deliverOpenURLs(_:)`.

Установите приложение в каталог пользователя и зарегистрируйте его в Launch Services:

```sh
./scripts/install-app.sh
```

Установщик собирает Release-сборку и устанавливает её в `~/Applications/PangoZip.app`. Для уже собранного приложения можно выполнить `./scripts/install-app.sh --skip-build`. Другой путь можно указать последним аргументом. Установщик не требует `sudo` и отказывается заменять существующий элемент, если его bundle identifier не `app.pangozip.desktop`.

Установщик вызывает `lsregister -f` для приложения и `/System/Library/CoreServices/pbs -update` для обновления кэша Services. Путь `pbs` присутствует в macOS 26; его справка перечисляет `-update`. Apple описывает `pbs` как отладочный инструмент без гарантированного интерфейса, поэтому установщик проверяет наличие исполняемого файла до вызова. Система может поместить команды в «Службы», а доступность и расположение пунктов зависят от версии macOS и приложения Finder. При необходимости сочетания клавиш для системных служб настраиваются пользователем в «Системные настройки → Клавиатура → Сочетания клавиш → Службы». Видимость пунктов следует проверить вручную после установки на macOS 26.
