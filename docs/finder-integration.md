# Finder Sync и фоновые операции

Подменю **PangoZip** добавляется непосредственно в основное контекстное меню Finder через `FIFinderSync`. Наблюдаемая область — `/`, включая локальные тома; расширение не обходит дерево и не добавляет badges. Облачные провайдеры могут ограничивать поддержку Finder Sync; проверка каждого провайдера и внешнего тома не выполнена.

## Выделение и команды

Состав и порядок основных архивных команд сверены с [исходным ContextMenu.cpp 7-Zip](https://github.com/ip7z/7zip/blob/main/CPP/7zip/UI/Explorer/ContextMenu.cpp).

Для файлов и папок: «Добавить в архив…», «Добавить в “имя.7z”», «Добавить в “имя.zip”». Все три команды создают новый архив из выделенного; команды выбора существующего архива в Finder-меню больше нет. В запросах старого расширения action=add также означает создание нового архива.

Для архивов перед ними идут: открытие, распаковка с выбором папки, распаковка здесь, распаковка в одноимённые папки, тестирование. В смешанном выделении эти команды берут только архивы, а упаковка включает весь набор. Имена быстрых команд учитывают выделение: для нескольких объектов — имя родительской папки, для одного файла с единственным расширением — имя без расширения; имя папки сохраняется. Если имя совпадает с выбранным исходным архивом, предлагается суффикс `_2` (далее `_3` и т. д.), чтобы быстрая команда явно создавала новый архив.

«Добавить в архив…» открывает NSSavePanel с параметрами формат/сжатие/solid/потоки/пароль и подтверждение пароля. Начальные значения читаются из настроек, изменения в этом диалоге действуют только на текущую операцию. Занятый путь и несовпадение паролей отклоняются. Быстрые команды не показывают диалог и выбирают свободное имя при коллизии. Пароль включает AES-256 для ZIP и скрытие заголовков 7z.

«Распаковать здесь» публикует верхние объекты рядом с исходником; «Распаковать…» — в выбранную папку без дополнительной обёртки. «Распаковать в “имя/”» сохраняет существующее поведение с отдельной папкой для каждого архива. Ранее существовавшие файлы/папки не заменяются и не объединяются: используется свободный числовой суффикс. Тестирование вызывает `7zz t`, не создаёт извлечённых файлов и не меняет архив.

До 10 000 выделенных объектов; дубликаты путей убираются. Папка с расширением `.zip` остаётся папкой. Реальный формат проверяет движок; меню использует расширение/UTType. Windows-команды почтового MAPI и отдельное Windows-меню контрольных сумм не перенесены.

## Процессы и данные

`FinderExtension` содержит только меню и передачу выбора. Каждый пункт хранит идентификатор снимка выделения через `NSMenuItem.tag`, поскольку произвольный Swift-объект в `representedObject` не проходит сериализацию Finder.

Запрос JSON передаётся через отдельный именованный NSPasteboard с UUID, не меняет общий буфер обмена и не создаёт временных request-файлов. URL `pangozip://finder?request=UUID` для открытия или `pangozip-worker://finder?request=UUID` для фоновой операции доставляется явно выбранному приложению. При чтении проверяются схема, UUID, размер и локальные URL; канал освобождается после чтения, ошибки запуска или через 120 секунд в живом расширении.

Открытие отправляется основному `PangoZip.app`. Остальные действия запускают новый `Contents/Helpers/PangoZipWorker.app` через NSWorkspace. Это отдельный bundle с `LSUIElement=true`, компактным окном и отключённым восстановлением окон. Он читает настройки из домена основного приложения, не показывает браузер архива и не регистрируется как Services provider. После успеха/отмены очищает workspace и завершает процесс. Пароль хранится только в памяти, ошибки остаются видимыми до закрытия.

## Создание и извлечение

Архив создаётся из снимков исходных файлов в транзакционной папке рядом с результатом, затем проверяется `7zz t` и листингом. Извлечение проверяет пути, общий объём и отсутствие ссылок/специальных файлов; каждый файл записывается потоком `7zz x -so` с лимитом объявленного размера. Файлы получают quarantine исходного архива. В tar.gz/tgz и аналогах дополнительно снимается слой сжатия.

Готовый архив/каталог публикуется атомарным `renamex_np(RENAME_EXCL)` с подбором свободного суффикса. Существующие данные не перезаписываются. Ошибка или отмена убирает частичный результат текущего архива. В пакете ранее завершённые результаты сохраняются, обработка останавливается на первом сбое; неверный пароль можно повторить для текущего архива.

## Сборка и установка

`scripts/build-app.sh` собирает расширение с `-application-extension` и точкой входа `_NSExtensionMain`, упаковывает helper и подписывает вложенные компоненты до основного приложения. `scripts/install-app.sh` регистрирует расширение через `pluginkit -a`, включает `pluginkit -e use`. Настройки программы открывают штатный интерфейс управления Finder extensions.

Подпись ad hoc предназначена для локальной разработки. Распространение потребует Developer ID и notarization. Основные официальные источники: [Finder Sync](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html), установленный SDK FinderSync.framework, AppKit NSWorkspace/NSPasteboard и SwiftUI.
