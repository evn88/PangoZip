# PangoZip 0.7.0

## Изменения

- Обычные ZIP, 7z и TAR, а также числовые многотомные архивы извлекаются одним пакетным запуском 7zz. Предпросмотр по-прежнему извлекает только выбранный файл. Для других многотомных схем оставлен прежний последовательный способ.
- Перед извлечением проверяются пути, коллизии, ссылки и общий объём. Движок работает в частной временной папке; фактический состав и размеры проверяются до публикации. Сохраняются quarantine и права доступа. Существующие файлы не перезаписываются.
- В окне архива появилась очередь добавления, удаления и извлечения. Пока одна операция выполняется, можно поставить следующую. Ожидающую задачу можно удалить, очередь — очистить. Ошибка приостанавливает очередь до явного продолжения. Закрытие окна отменяет ожидающие задачи.
- Кнопка отката и ⌥⌘Z восстанавливают состояние до последнего изменения архива в текущем сеансе. Откат доступен один раз, без redo; при внешнем изменении архива он запрещён. Для отката сначала завершите редактирование рабочих копий командой «Сохранить в архив». Закрытие архива очищает снимок для отката.
- Обновления из GitHub Releases проверяются через Sparkle. Настройка автоматической проверки находится в «Обновлениях», ручная проверка — также в меню PangoZip. Лента и пакеты подписываются Ed25519; ключ для выпуска хранится в GitHub Actions, открытый ключ — в приложении. Установка предлагает перезапуск и учитывает операции, другие экземпляры приложения и отказ закрыть изменённые файлы.

Первая версия с механизмом обновлений устанавливается вручную. Версии 0.6.1 и старше не имеют updater. Для последующих обновлений необходим опубликованный релиз с подписанным `appcast.xml`. Подробности: [автообновления](automatic-updates.md).

Версия приложения и компонентов: 0.7.0, сборка 12.
