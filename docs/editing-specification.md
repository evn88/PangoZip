# Редактирование архивов и основной список

Источники: требования владельца 10.10.2026, решение сохранять рабочие файлы кнопкой/⌘S, локальное руководство 7zz 26.04. Новые требования заменяют запрет записи и срок жизни кэша первого этапа. Atlas/Smart Monitor не относятся к проекту.

- Основная широкая таблица-дерево: имя, размер, создание, изменение, права, владелец. Отсутствующие в архиве метаданные — прочерк. Справа скрываемый предпросмотр 320–400 pt, окно около 1480 pt, горизонтальная прокрутка на узком экране.
- Верхняя панель: открыть/закрыть архив, добавить файлы/папки, удалить, открыть файл, редактировать, сохранить в архив, скрыть/показать предпросмотр. Нативный выбор нескольких строк и навигация. Добавление в выбранную папку либо рядом с выбранным файлом, без выделения в корень. Удаление и перезапись совпадающих имён подтверждаются.
- Редактирование: отдельная временная рабочая копия, внешнее приложение; пользователь сохраняет в редакторе, затем ⌘S в PangoZip. При смене/закрытии архива с рабочими копиями: сохранить, отменить или удалить. Изменения не теряются молча.
- Запись ZIP/7z/TAR по реальному типу. RAR и другие неподдерживаемые типы только для чтения. Шифрование нельзя снимать незаметно; зашифрованные архивы требуют пароль.
- Любая запись — на копии рядом с оригиналом, проверка целостности/списка, атомарная замена неизменившегося оригинала. Отмена/ошибка сохраняет оригинал. Записи сериализованы, устаревшие сеансы запрещены.
- Finder: основное подменю PangoZip предоставляет Finder Sync Extension; резервные NSServices находятся в «Службах». Команды создания упаковывают выделенные файлы и папки в новый архив, команды открытия и извлечения работают с выбранными архивами. Установка в ~/Applications включает расширение и регистрацию Launch Services. Холодный запуск не теряет команду. Подробности: [интеграция Finder](finder-integration.md).
- Клавиши: ⌘O открыть, ⌘W закрыть архив, ⌘⇧A добавить, ⌘⌫ удалить, ⌘↩ открыть файл, ⌘E редактировать, ⌘S сохранить, ⌘⇧P предпросмотр, ⌘F поиск, Escape отменить. Стрелки и ⌘A нативные.
- Временные файлы удаляются при закрытии/смене архива и штатном выходе после завершения отменённых задач. Остатки после аварии очищаются при следующем запуске; активные процессы не затрагиваются.

Проверяемые границы: реальные добавление/удаление/замена, literal wildcard, папки, шифрование, внешний конфликт, отмена/ошибка без повреждения оригинала, очистка и метаданные. UI/Finder проверяются вручную на тестовых данных.
