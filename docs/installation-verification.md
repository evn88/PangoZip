# Установка и удаление PangoZip 0.4.1

## Поведение

Приложение содержит Finder Sync в `Contents/PlugIns`, помощник операций в `Contents/Helpers` и программу удаления в `Contents/SharedSupport/Uninstall PangoZip.command`. Внешние LaunchAgent/LaunchDaemon не создаются.

Установщик проверяет подпись, комплект компонентов и отсутствие активного приложения/помощника. Предыдущая версия сохраняется на время замены; ошибка восстанавливает её. PlugInKit проверяется по версии и установленному пути с ограниченным повтором регистрации. После уборки резервной копии регистрация подтверждается повторно. Перезапускается только расширение данного установленного приложения, Finder не завершается.

Программа удаления отключает расширение, снимает регистрацию приложения, помощника и расширения, завершает процессы своего расширения и переносит весь комплект в Корзину. Работающее приложение или операция с архивом препятствуют удалению. При ошибке до перемещения регистрация восстанавливается. Пользовательские настройки сохраняются.

При ручном удалении уже загруженное расширение проверяет наличие файлов основного приложения и помощника перед созданием меню и отправкой команды. Путь через `.Trash`/`.Trashes`, включая символические ссылки, недоступен. Уже открытое меню следует закрыть и открыть заново. macOS обслуживает собственный реестр и кэши, поэтому мгновенная очистка всех записей при ручном удалении не гарантируется. Если сохранена другая копия приложения, macOS может обнаружить её расширение; для полного отключения используется программа удаления.

В sandbox расширения проверка собственного родителя опирается на расположение расширения и метаданные файлов. Чтение родительского Bundle ограничивается sandbox, дополнительные разрешения не добавляются.

Архитектура расширения соответствует [Finder Sync App Extension Programming Guide Apple](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html). Регистрация проверена также по локальному `man pluginkit`; macOS автоматически обслуживает реестр, явные команды ограничены установкой и удалением.

## Проверки 11.10.2026

- XCTest: 42 теста ядра и 2 теста приложения, включая удаление основного комплекта, отсутствие помощника, Корзину, ссылку на Корзину и чужой bundle.
- Формат Swift, синтаксис shell, release-сборка и проверка подписи всего комплекта.
- Отдельная реальная установка тестового комплекта в путь с пробелами.
- Искусственная ошибка перемещения новой версии: предыдущий executable восстановлен с совпадающим SHA-256, временная папка установщика удалена.
- Реальное удаление тестового комплекта через встроенный native helper: приложение перемещено в Корзину, расширение отключено в PlugInKit. Собственный тестовый комплект затем убран.
- Установщик и деинсталлятор при работающем PangoZip завершились отказом; установленное приложение осталось на месте. В интерфейсе настроек подтверждена кнопка программы удаления.
- В Finder проверено наличие основного подменю PangoZip. После временного перемещения установленного приложения в тестовую папку `.Trash` новый вызов контекстного меню не содержит подменю PangoZip. Приложение восстановлено, регистрация обновлена.

## Распространение

`./scripts/package-app.sh` формирует `build/PangoZip-Installer.zip` с приложением, самостоятельными командами установки и удаления и инструкцией. Исходники и Xcode на машине пользователя не нужны. Сборка остаётся локальной ad hoc; Developer ID и нотариализация необходимы для публичного распространения и не входят в эту проверку.
