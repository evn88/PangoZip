# PangoZip 0.6.1

- Доступно 30 колонок. Колонки выбираются кнопкой на панели инструментов или правым кликом по заголовку таблицы. Выбор сохраняется между запусками. По умолчанию: имя, размер, тип, сжатие, дата изменения. Имя остаётся видимым.
- Дополнительные сведения включают размер в архиве, метод, даты, права, владельца и группу, шифрование, CRC, путь, признаки ссылок, счётчики вложенных файлов и папок, технические поля 7zz. Отсутствующие значения показаны прочерком; размер общего solid-блока не выдаётся за размер отдельного файла.
- «Извлечь» отображается иконкой. «Поделиться архивом» открывает системное меню отправки текущего архива.
- Панель операции стала компактной: полоса прогресса и строка полезных показателей; неизвестные и неприменимые метрики скрыты.
- Исправлена взаимная блокировка при переносе пустой папки в Finder: получатель File Promise уже согласовывает запись, повторный NSFileCoordinator не нужен. Атомарная публикация по-прежнему не перезаписывает существующий объект.
- Изменения рабочих копий автоматически записываются в архив после сохранения во внешнем редакторе. Два стабильных наблюдения с интервалом около секунды отделяют запись редактора от транзакции архива. Повторные сохранения поддерживаются, копия остаётся до закрытия архива. Ошибка показывается пользователю; одну и ту же неудачную версию приложение не пытается записывать бесконечно. Ручная команда сохранения остаётся для повторной попытки и завершает цикл редактирования, после чего файл можно удалить или заменить.
- До закрытия архива завершите работу с документом в редакторе: несохранённый в редакторе буфер PangoZip прочитать не может. Закрытие конкретного документа не является универсальным событием macOS; по согласованию с пользователем используется сохранение файла.
- В настройках появилась вкладка типов архивов с текущими обработчиками и назначением PangoZip для выбранных форматов. Снятие отметки исключает формат из следующего назначения, не сбрасывая неизвестный прежний обработчик.

Версия приложения и встроенных компонентов: 0.6.1, сборка 11.
