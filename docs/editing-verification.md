Проверки 10–11.10.2026, Apple Silicon, Xcode 27.0, Swift 6.4, deployment macOS 26.

- Отмена, ошибки подготовки и внешнее изменение оригинала не перезаписывают архив; транзакционные каталоги убираются.
- Закрытие удаляет preview и edit copies одного сеанса, оставляет другой активный сеанс. Recovery удаляет остатки завершённого процесса и его sidecar-транзакцию, сохраняя активный workspace.

- Приложение установлено в ~/Applications и зарегистрировано через lsregister/pbs. Компактные кнопки и скрытие/восстановление предпросмотра проверены в UI.
- 11.10.2026: toolbar разделён на три группы (архив, добавление/удаление, работа с файлом), переключатель предпросмотра отдельно справа; визуально проверено в установленном приложении.
- Finder Sync зарегистрирован, включён и работает под локальной ad hoc подписью. Подменю PangoZip увидено непосредственно в основном меню Finder: для двух текстовых файлов доступны упаковка/добавление, для архива дополнительно открытие/извлечение.

- Первоначальный запуск через аргумент OpenConfiguration не доставлял флаг фонового режима; заменён отдельным вложенным PangoZipWorker.app и схемой pangozip-worker. URL-маршрут проверяет токен и локальное выделение.
- Ручной Finder: создан 7z с несколькими выделенными объектами; извлечён 7z, повторное извлечение создало FinderDemo (2), не затронув первый результат.
- Ручной helper: SecretFixture.zip показал компактное окно с вводом пароля; после ввода известного тестового пароля извлечён First.txt. Основной браузер не создавался.
- После окончательного исправления завершения helper процесс 4483 выполнил извлечение и завершился; основной процесс 2695 остался прежним. Упаковка через helper также завершает процесс автоматически.
- Ручные настройки: выбран 7z, команда «Заархивировать» создала First.txt.7z. Настройка возвращена на исходный ZIP; остальные настройки не менялись.
- Дополнительные тесты: смешанное выделение, папка с расширением ZIP, декодирование запросов, создание/извлечение ZIP и 7z, фактический метод Store/Copy при уровне 0, коллизии имён, tar.gz, пароль, лимит извлечения, ссылки и отмена без частичных результатов.
- Финальный swift test: 33 теста, 0 ошибок (11.10.2026 01:45). Swift format lint для Sources/FinderExtension/Tests/Package.swift, release build, codesign --verify --deep --strict и pluginkit проверка прошли. Обновление установлено в ~/Applications/PangoZip.app.


Не проверены Intel Mac, все форматы документов и все архивные методы. RAR и сжатые TAR намеренно только для чтения в редакторе; Finder-извлечение поддерживает сжатые TAR. Не проверены все облачные провайдеры и внешние тома; ссылки/специальные файлы при полном извлечении пока отклоняются. Никакие пользовательские архивы в функциональных проверках не изменялись: использовались временные fixture и build/EditingDemo.zip.

## Взаимодействие с файлами внутри менеджера, 0.3.1

Добавлены контекстное меню NSOutlineView, извлечение выделения (⌘⇧E), native drop файлов/папок в нужную папку архива и исходящие NSFilePromiseProvider. Подробное поведение и ограничения проверки: [file-interactions.md](file-interactions.md).

Тестовый набор расширен до 39 XCTest: 37 core и 2 app. App-тесты выполняют callback File Promises с настоящим движком, проверяют последовательную запись папки и файла, снятие lease после завершения/отмены и ошибку для закрытого сеанса. Ручной UI подтвердил меню ПКМ и извлечение Photo.txt. Полный gesture drag между окнами не подтверждён из-за ошибки cua_repl noWindowsAvailable; это ограничение ручной проверки, а не подтверждённый успешный UI-сценарий.

## Семантика меню Finder, 0.4.0

По уточнению пользователя команда «Добавить в архив…» означает создание нового архива из выделения. Выбор существующего архива из Finder-меню убран; добавление в уже открытый архив сохранено в менеджере.

Меню упорядочено по основным архивным командам исходного 7-Zip ContextMenu.cpp: открытие, три режима распаковки, тестирование, диалог создания, быстрые 7z/ZIP. Имена учитывают одиночный файл/папку, множественное выделение и конфликт с именем выбранного исходного архива (`_2`).

NSSavePanel helper позволяет выбрать имя, место, формат, сжатие, solid, потоки и пароль/подтверждение. Новые пароли включают AES-256 ZIP или шифрование заголовков 7z и не записываются в настройки. Delegate отклоняет занятый путь и разные пароли. Основное окно менеджера для этих действий не запускается.

Тесты расширены до 41 XCTest (39 core + 2 app): порядок и подписи меню, новая семантика, имена, распаковка здесь/в выбранную папку без обёртки и без перезаписи, создание зашифрованных ZIP/7z и `7zz t` с правильным/неправильным паролем.

Ручной Finder: для Photo.txt показаны «Добавить в архив…», «Добавить в “Photo.7z”» и «Добавить в “Photo.zip”». Через первый пункт открыт диалог именно нового архива, создан build/InteractionDemo/destination/CreatedFromMenu.zip с Photo.txt; отдельная проверка `7zz t` вернула Everything is Ok. Helper завершился автоматически; основной процесс остался прежним. Для ZIP в основном контекстном меню увидены все восемь архивных команд, включая распаковку здесь и тестирование.
