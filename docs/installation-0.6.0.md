# Установка PangoZip 0.6.0 перетаскиванием

Дата: 11.10.2026. Предварительная arm64-сборка для macOS 26+.

## Пользовательский сценарий

1. Открыть DMG, перетащить PangoZip.app на ярлык Applications.
2. Дождаться копирования, извлечь образ и открыть установленное приложение.
3. Если расширение Finder ещё выключено, нажать «Включить меню Finder…» и разрешить PangoZip в системных настройках.

В корне образа ровно три элемента: приложение, ссылка Applications → /Applications и Read me.txt. Install/Uninstall .command в образе больше нет. Все помощники и Finder Sync Extension остаются внутри приложения. Внешние LaunchAgent, LaunchDaemon и привилегированные службы не устанавливаются.

## Первый запуск

`FinderRegistrationPlan` проверяет реальную локацию /Applications или ~/Applications, структуру комплектов, идентификаторы и исполняемые файлы. Запуск с DMG, из Downloads, AppTranslocation и Корзины не выполняет регистрацию. Проверка не доверяет одному строковому префиксу пути и отклоняет вложенность в другое приложение.

В основном приложении вызывается публичный LSRegisterURL для родительского bundle и встроенного worker. Вызовы выполняются вне главного потока; отмена ждёт активный вызов. Finder Sync обнаруживает сама macOS. Успешная регистрация не подменяет системное согласие на включение расширения.

При возвращении из системных настроек статус перечитывается. Показаны состояния подготовки, включённого расширения, необходимого согласия, запуска не из Applications и ошибки с повтором. Worker не выполняет такую подготовку; настройки интеграции доступны только в основном приложении.

Finder Extension дополнительно проверяет установленную локацию перед показом меню и доставкой команды, поэтому новая копия из build/DMG/Корзины не предлагает действия. Обычное удаление — закрыть приложение, дождаться фоновых операций и переместить его в Корзину; вложенные компоненты удаляются вместе с ним, доступность меню проверяется заново. Настройки пользователя сохраняются.

## Проверки

- 70 XCTest: 59 ядра и 11 приложения, без ошибок. Новые тесты проверяют разрешённую локацию и компоненты, ошибки/порядок регистрации, ожидание отмены и системное согласие без записи тестов в реестр macOS.
- Строгий формат Swift, синтаксис shell, четыре plist и release-сборка прошли.
- DMG создан, hdiutil verify успешен; read-only mount проверяет точный состав и ссылку Applications. Подписи и лицензии/исходники 7-Zip сохранены.
- Реальная копия 0.6.0 перенесена в /Applications обычным копированием, без install-app.sh, lsregister -f, pluginkit -a или pluginkit -e. После первого запуска PlugInKit обнаружил включённое расширение 0.6.0 из установленного bundle, Launch Services содержал вложенный worker, настройки приложения показывали включённое расширение.
- Прежние дубли 0.5.0 сохранены в Корзине; после этого PlugInKit показывал единственную установленную копию 0.6.0.

Эта проверка использовала ранее разрешённое расширение на машине разработки. Новый пользователь всё ещё может получить штатный запрос включения Finder Extension. Отдельная чистая macOS-машина и Gatekeeper после интернет-загрузки не проверены.

## Подпись и Gatekeeper

На скриншоте владельца Gatekeeper блокировал неподтверждённый Install PangoZip.command. Отказ от скрипта устраняет этот лишний запуск, но не заменяет подпись самого приложения.

На машине сборки нет сертификата Developer ID Application; сборка подписана ad hoc и не нотариализована. macOS может заблокировать скачанное приложение. Для обычного распространения без такого предупреждения нужен Developer ID и нотариализация Apple, а не снятие quarantine или отключение системной защиты.

Источники Apple: [LSRegisterURL](https://developer.apple.com/documentation/coreservices/1446350-lsregisterurl), [создание и установка содержащего приложения](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/ExtensionCreation.html), [Finder Sync](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html), [подпись Developer ID](https://developer.apple.com/developer-id/), [нотариализация](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).
