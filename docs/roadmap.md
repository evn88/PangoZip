# План развития

Здесь записаны согласованные доработки, которые отложены на следующие этапы. Каждая описана настолько, чтобы её можно было взять в работу без повторного обсуждения. Порядок внутри раздела не задаёт приоритет.

## Поиск по содержимому

Искать текст внутри файлов архива, а не только по именам.

- Поиск запускается отдельным режимом поля поиска, обычный поиск по именам остаётся мгновенным.
- Файлы извлекаются потоком в приватный временный каталог сеанса и удаляются сразу после проверки. На диск вне этого каталога ничего не попадает.
- Просматриваются только текстовые файлы; двоичные и превышающие лимит размера пропускаются, их число показывается в итоге.
- Поиск отменяется, показывает прогресс и не блокирует просмотр архива.
- Результат: список файлов с числом совпадений и строкой контекста; выбор результата выделяет файл в дереве.
- Архив с паролем использует уже введённый пароль сеанса.

## Сравнение архивов

Сравнить архив с папкой или с другим архивом: что добавлено, изменено, удалено.

- Сопоставление по относительному пути. Изменение определяется по размеру и CRC из списка архива; для папки на диске CRC считается по требованию.
- Результат показывается таблицей с фильтром по виду различия и итоговыми счётчиками.
- Сравнение ничего не меняет ни в архиве, ни в папке.
- Отдельным шагом можно добавить экспорт отчёта в текстовый файл.

## Выбор кодировки имён

Для старых ZIP с кириллицей и другими национальными кодировками, когда автоопределение ошиблось.

- Команда «Кодировка имён» в окне архива со списком распространённых кодировок (CP866, CP1251, KOI8-R, Shift JIS, GBK, EUC-KR, CP437, UTF-8) и предпросмотром нескольких имён до применения.
- Выбор передаётся движку ключом `-mcp` при чтении списка и извлечении и действует до закрытия архива.
- Архив, открытый с ручной кодировкой, доступен только для чтения, чтобы не записать имена в неверной кодировке.

## Условия для отслеживаемых папок

Первая версия отслеживаемых папок задаёт одну папку назначения на правило. Следующий шаг: условия, по которым для одной отслеживаемой папки можно указать несколько путей распаковки.

- Правило состоит из отслеживаемой папки и упорядоченного списка назначений. У каждого назначения есть условие и путь.
- Условия: расширение архива, маска имени, размер, формат. Срабатывает первое подходящее назначение; последнее безусловное служит запасным.
- Настройка «удалять архив после извлечения» задаётся для каждого назначения отдельно.
- В настройках условия редактируются списком с перестановкой строк; порядок определяет приоритет.
- Модель правил уже хранит список назначений, поэтому новая версия читает старые настройки без миграции.

## App Intents и «Команды»

Действия «Создать архив», «Извлечь», «Проверить архив» для Shortcuts, Spotlight и автоматизаций.

- Каждое действие принимает файлы и параметры (формат, профиль сжатия, папка назначения) и возвращает созданные или извлечённые файлы.
- Действия выполняются тем же `ArchiveService`, что и приложение, с теми же проверками и транзакционностью.
- Архив с паролем: пароль передаётся параметром действия и не сохраняется.
- Долгие операции сообщают прогресс системе и поддерживают отмену.

## Большие архивы

Проверить скорость списка и поиска на архивах в сотни тысяч записей.

- Подготовить генератор тестовых архивов на 100 тысяч, 500 тысяч и миллион записей и зафиксировать время открытия, построения дерева, поиска и пиковую память.
- Задать целевые значения и добавить тест производительности, который ловит заметное ухудшение.
- Если целевые значения не достигаются: строить дерево лениво по раскрываемым папкам, вести поиск в фоне с выдачей результатов порциями, не хранить повторяющиеся части путей.

## Повреждённые и враждебные архивы

Набор регрессионных тестов на опасные входные данные.

- Zip-бомбы: вложенные и с перекрывающимися записями; извлечение должно остановиться по лимиту размера.
- Пути с `..`, абсолютные пути, имена с управляющими символами и зарезервированными именами.
- Символические и жёсткие ссылки, указывающие за пределы каталога извлечения, в том числе цепочки ссылок.
- Обрезанные и повреждённые архивы, неверные заголовки, неверные размеры в заголовках.
- Дубликаты имён, отличающиеся только регистром или нормализацией Unicode.
- Для каждого случая проверяется, что вне каталога назначения ничего не создано, а пользователь получает понятную ошибку.
