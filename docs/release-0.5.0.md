# PangoZip 0.5.0: подробный прогресс и первый DMG

Предварительный релиз для macOS 26+ на Apple Silicon (arm64). Собственный код — SwiftUI/AppKit, движок — официальный bundled 7-Zip 26.04. Intel-сборка в этот релиз не входит.

## Прогресс

За образец взяты показатели [окна прогресса Windows 7-Zip](https://github.com/ip7z/7zip/blob/main/CPP/7zip/UI/FileManager/ProgressDialog2a.rc): размер, обработанные данные, скорость, файлы, прошедшее и оставшееся время. Формат консольных сообщений проверен по bundled исходникам `CPP/7zip/UI/Console/PercentPrinter.cpp` версии 26.04; он содержит целый процент, а не точный счётчик байтов.

- Создание: логический размер готовых рабочих копий и число файлов определяются перед запуском сжатия. Показан текущий размер создаваемого архива.
- Извлечение и экспорт: общий объём берётся из проверенного списка записей; текущий файл известен точно. Завершённые файлы считаются после успешного завершения движка и проверки фактического размера.
- Промежуточный объём — оценка по процентам движка, обозначенная `≈`. На границах файлов/этапов счётчики точные. Папки не прибавляют байтов; пустые файлы учитываются в количестве.
- Скорость — средняя по байтам текущего этапа, доступна после первых данных и не менее 0,5 секунды. Оставшееся время — оценка до конца этого этапа, а не обещание времени всей операции. Оценка не отсчитывается искусственно между событиями.
- Прошедшее время включает подготовку и остальные этапы; расчёты скорости используют монотонные системные часы. Интерфейс обновляет прошедшее время раз в секунду.
- Проверка архива имеет собственный объём обработанных данных. После сжатия счётчик байтов начинает этап проверки заново; общий процент продолжает расти.
- Общие 100% появляются после успешной проверки и публикации результата. Ошибка либо отмена не изображаются успешным завершением.
- Неизвестные показатели отображаются прочерком. Подготовка файлов имеет неопределённый прогресс и прошедшее время.

## DMG

`scripts/package-dmg.sh` собирает версионный UDZO/HFS+ образ `PangoZip-<version>-<arch>.dmg`. Проверяет подпись, архитектуры основного приложения/помощника/расширения/программы удаления, наличие лицензий и полных исходников 7-Zip. Готовый образ заменяется после успешного `hdiutil verify`, временный каталог очищается при завершении и ошибке.

В корне диска: `PangoZip.app`, `Install PangoZip.command`, `Uninstall PangoZip.command`, `Read me.txt`. Установщик работает с read-only тома, копирует полный комплект в `~/Applications` и регистрирует Finder Sync и помощник. Для установки не нужны Xcode, исходники PangoZip или отдельный 7-Zip. Подробная [инструкция](installation.txt) включена в образ.

## Проверки

- 60 XCTest: 52 ядра и 8 приложения, без ошибок. Среди новых проверок — объёмы и счётчики при настоящем сжатии/извлечении/экспорте, оценка скорости и времени, нулевые/неизвестные значения, границы UInt64, отсутствие обхода символических ссылок, русские десятичные единицы и длительности более суток.
- Строгий формат Swift, синтаксис shell и четыре plist проверены.
- Release `.app` собран и подписан; глубокая строгая проверка подписи успешна.
- DMG успешно создан и проверен; readonly-монтирование и установка с образа проверены. PlugInKit подтвердил активное расширение 0.5.0 из установленного приложения, ресурс иконки совпал с исходным ICNS.
- Независимое ревью подтвердило последовательную доставку событий, ожидание отменённого копирования/процесса и выдачу общего 100% после публикации. Замечание о преждевременном подтверждении файла на raw 100% исправлено и закреплено тестом.

## Ограничения первого релиза

Подпись ad hoc, без Developer ID и нотариализации Apple: на машине сборки доступен только Apple Development, который не заменяет Developer ID для распространения. Gatekeeper может блокировать скачанную команду/приложение; автоматический проход этой проверки не подтверждён. Защита macOS не отключается. Релиз помечен как предварительный.

Проверено на Apple Silicon. UI-автоматизация нового окна прогресса на момент подготовки отчёта была недоступна из-за заблокированного Mac; визуальная проверка размеров и отображения всех новых полей пока не подтверждена. Существующие ограничения размеров и времени операций из README сохраняются. Полный перенос мышью между Finder и приложением, VoiceOver и все сторонние Quick Look providers в этом релизе не проверялись.
