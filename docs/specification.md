# PangoZip: первый этап

Источник требований: решения владельца в чате от 10.10.2026. Новый проект SwiftUI, macOS 26+, движок 7zz. Keka удаляется полностью.

## Поведение

- Открытие локального архива через диалог, Finder «Открыть с помощью» и перетаскивание.
- Дерево папок и файлов, включая неявные папки; поиск по пути. Размер выбранного файла.
- Выбор файла извлекает только его в приватный временный каталог. Изображения и документы отображает системный Quick Look. Неподдерживаемые форматы можно открыть внешним приложением.
- Открытие выбранного файла в приложении по умолчанию. Кэш сохраняется до завершения PangoZip, чтобы не сломать внешнее открытие; изменения во внешнем приложении не записываются в архив.
- Пароль вводится при открытии архива и может быть изменён для зашифрованного файла. Не сохраняется на диск и не выводится в ошибки. Аргумент процесса 7zz может быть доступен локальным инструментам просмотра процессов.
- Загрузка, пустой архив, ошибка движка, повреждённый архив, отмена и отсутствие подходящего предпросмотра имеют явное состояние.

## Ограничения и решения

- Чтение архива не означает отсутствие декодирования: solid-блоки могут требовать обработки соседних файлов.
- Предпросмотр ограничен 200 MiB на файл. Листинг ограничен 32 MiB; процесс ограничен 120 секундами. Устаревшая операция отменяется при новом выборе или архиве.
- Пути с обходом каталогов, абсолютные пути, неоднозначные дубликаты, симлинки и специальные файлы отклоняются. Извлечение идёт в stdout, а приложение само выбирает безопасное имя файла.
- Тестируемые границы: чтение реального архива, дерево, точный выбор имени без wildcard, пароль, ошибки, ограничения, отмена, очистка кэша. UI проверяется сборкой и ручным запуском.
- Движок поставляется внутри .app с оригинальными лицензиями. Подписание для локального запуска ad hoc; Developer ID и notarization не входят в этот этап.
- Название PangoZip выбрано пользователем; проверка уникальности названия не проводилась.
